KEN'S VOICE MESSAGE
===================

1. Put your recording in THIS folder and name it exactly:   ken-voice-message.mp3
   (overwrite the placeholder file that is already here - do not edit index.html)

2. Any normal audio file usually works: a phone voice memo, WhatsApp export, m4a/aac/ogg
   renamed to .mp3, or an MP3 from anywhere. Keep the ".mp3" ending.
   If a renamed file refuses to play, convert it to a real mp3 first - the page will
   simply show "Ken's voice message isn't uploaded yet" instead of pretending.

3. The page shows the real length of the file and plays it with the
   "Play a VM from Ken" button - nothing else needs to change.

Note: ken-voice-message.mp3 shipped here is a 12 second silent placeholder
generated on purpose (raw MPEG-1 Layer III, 128 kbps, 44.1 kHz, joint stereo,
with a LAME-style "Info" frame header so players know the length up front).
Delete it once your own file is in place.
